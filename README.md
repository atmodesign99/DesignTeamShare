# Share Split Calculator

نسخه ۱.۲ — محاسبه‌گر سهم مشارکت اعضای پروژه بر اساس وزن بسته‌های کاری، زیربخش‌های منطقی، مدیریت پروژه و بازاریابی.

## تغییرات نسخه ۱.۲

- اضافه شدن الگوی پیشنهادی زیربخش برای تمام گزینه‌های نرخ‌نامه.
- وقتی روی «تقسیم به زیربخش» می‌زنید، ابزار بر اساس کد همان خدمت، زیربخش‌های پیش‌فرض مناسب را اعمال می‌کند.
- امکان اعمال دستی الگوهای مهم مثل گزارش سالانه، هویت بصری، بسته‌بندی، UI وب‌سایت، Key Visual و ساختار صفحه‌آرایی باقی مانده است.
- اضافه شدن «بازاریابی و جذب پروژه» به‌عنوان بسته مجازی درصدی، مشابه مدیریت پروژه.
- مدیریت پروژه و بازاریابی دیگر اسلایدر ندارند و درصدشان با input عددی وارد می‌شود.

## منطق محاسبه

وزن بسته کاری = تعرفه پایه × تعداد × ضریب پیچیدگی

اگر بسته به زیربخش تقسیم شود:

وزن هر زیربخش = وزن بسته × درصد وزن زیربخش

امتیاز هر عضو از هر زیربخش = وزن زیربخش × درصد مشارکت عضو در آن زیربخش

مدیریت پروژه و بازاریابی، در صورت فعال بودن، به‌عنوان بسته مجازی درصدی از جمع وزن بسته‌های کاری اضافه می‌شوند و بین اعضا تقسیم می‌شوند.
